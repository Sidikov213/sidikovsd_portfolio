# Как задеплоить сайт на хостинг Рег.ру

Пошаговая инструкция для размещения портфолио на домене и хостинге Рег.ру.

---

## Шаг 1. Собрать статическую версию сайта

На своём компьютере в папке проекта выполните в терминале:

```bash
npm install --legacy-peer-deps
npm run build
```

После сборки появится папка **`out`** — это и есть готовый сайт (HTML, CSS, JS, картинки).

---

## Шаг 2. Войти в панель хостинга Рег.ру

1. Зайдите на [reg.ru](https://www.reg.ru)
2. Войдите в личный кабинет
3. Откройте раздел **«Хостинг»** и выберите ваш подаренный хостинг
4. Запомните или сохраните:
   - **Логин и пароль FTP** (или данные для входа в файловый менеджер)
   - **Сервер FTP** (обычно `ftp.ваш-домен.ru` или указан в письме/панели)

---

## Шаг 3. Загрузить файлы на хостинг

### Вариант А: через FTP (FileZilla, WinSCP и т.п.)

1. Установите программу для FTP, например [FileZilla](https://filezilla-project.org/) или [WinSCP](https://winscp.net/).
2. Подключитесь к хостингу:
   - **Хост:** сервер FTP из панели Рег.ру
   - **Логин и пароль:** из панели хостинга
   - **Порт:** 21 (обычно)
3. На сервере откройте папку **`public_html`** (или **`www`** — как указано в инструкции Рег.ру).
4. **Важно:** в `public_html` должны лежать **содержимое** папки `out`, а не сама папка `out`.
   - То есть: скопируйте всё из `out` (включая папки `_next`, файлы `index.html` и т.д.) в `public_html`.

### Вариант Б: через файловый менеджер в панели Рег.ру

1. В панели хостинга найдите раздел «Файловый менеджер» или «Файлы».
2. Откройте папку **`public_html`**.
3. Загрузите туда все файлы и папки из вашей локальной папки **`out`** (можно архивом .zip, затем распаковать в панели).

---

## Шаг 4. Привязать домен к хостингу (если ещё не привязан)

1. В личном кабинете Рег.ру: **Домены** → ваш домен.
2. Укажите **DNS-серверы хостинга** (они указаны в разделе «Хостинг» в панели Рег.ру) или настройте A-запись на IP-адрес сервера хостинга.
3. Подождите от 15 минут до 24–48 часов, пока обновятся DNS.

Если домен и хостинг куплены в Рег.ру вместе, привязка часто уже настроена — проверьте в панели.

---

## Шаг 5. Проверить сайт

Откройте в браузере ваш домен (например `https://ваш-домен.ru`). Должна открыться главная страница портфолио.

---

## Краткая шпаргалка

| Действие              | Команда / место                          |
|-----------------------|------------------------------------------|
| Сборка сайта          | `npm run build` в папке проекта          |
| Готовые файлы для FTP | папка **`out`** в корне проекта          |
| Куда загружать        | **`public_html`** на хостинге            |
| Данные FTP            | В панели Рег.ру → Хостинг → Доступ по FTP |

---

## Если что-то не работает

- **Сайт не открывается:** проверьте, что все файлы из `out` лежат именно в `public_html`, а не в подпапке.
- **Страницы 404:** убедитесь, что загружена вся папка `out`, включая `_next` и все HTML-файлы.
- **Не подключается FTP:** проверьте логин, пароль и сервер в панели Рег.ру; при необходимости обратитесь в поддержку Рег.ру.

Удачи с деплоем.
